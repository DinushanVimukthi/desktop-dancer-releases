# 🕺 Desktop Dancer — Public Releases & Character Repository

Official public release repository for **Desktop Dancer**, the real-time audio-reactive desktop companion.

---

## 📥 Downloads

Download the latest standalone executable from our [Releases Page](https://github.com/DinushanVimukthi/desktop-dancer-releases/releases/latest).

No Python installation required—just unzip and run `DesktopDancer.exe`!

---

## 🎭 Character Packs Catalog

Desktop Dancer automatically checks this repository for new character releases and syncs them directly into your app.

Currently available characters:
- **Scooby-Doo** (Classic retro groove dancer)
- **Sonic the Hedgehog** (30 FPS breakdance with golden rings & speed trails)
- **Vibing Cat (Meme)** (30 FPS rhythm head-bobbing cat)
- **Pikachu** (30 FPS electric cheek-sparking cheer dance)
- **Cartoon Dog Mascot** (Upbeat bounce with floating musical notes)

---

## 🔄 Auto-Update & Metadata
The app queries [`version.json`](./version.json) to detect:
- New application versions & installer packages
- Newly released character packs (automatically downloaded to your `characters/` folder)
